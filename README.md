# 隐藏人格测试

8 道题的轻量心理小测试。凭第一反应选，看看你骨子里是**枭、犬、猫**还是**狐**。

## 玩法

打开页面 → 点「开始测试」→ 依次答完 8 题 → 查看结果和四种人格的得分条 → 可「再测一次」。

## 技术说明

- 单个 `index.html`，HTML / CSS / 原生 JavaScript 全写在一起
- **零外部依赖**：不加载任何 CDN、字体或图片资源，断网也能正常玩
- 计分逻辑在前端完成，不上传任何数据

## 本地预览

直接双击 `index.html` 用浏览器打开即可。

## 部署

代码托管在 GitHub，通过 Vercel 自动部署，每次 push 到 `main` 分支都会触发重新上线。
